# Catholic Education Unit – School Data

Website copy of the CEU school data tool: https://sethsakyi75-cmd.github.io/ceu-data/

Open it once with internet, then add it to the Home Screen (iPhone: Share → Add to Home Screen; Android: ⋮ → Add to Home screen).
After that it opens from the icon and works without internet. All data stays on each phone and on the office device;
nothing is sent to this website.

The source and tests live in the StanineGH repository (`ceu-data/`); this repository only holds the published copy.
